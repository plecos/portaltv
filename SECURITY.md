# Security

Please report a vulnerability privately to security@getportaltv.net, not in a public issue.
Say what you found, how to reproduce it, and which version (Settings, About Portal). I'll reply as
soon as I can and credit you in the fix if you'd like.

Portal's parent PIN and profile codes protect Portal's own screens, not the TV as a whole (see
"Known limits" in the README), so someone with adb or remote access to the TV can bypass them.
That is a known limit, not a vulnerability.
